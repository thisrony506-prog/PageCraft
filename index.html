How PageCraft works

🎨

1. Design both devices

Switch the preview between Desktop and Mobile and design each one separately — layout, headline size, spacing and columns. Or click anything in the big preview and edit its text, font, colour, image and button style right there.

📢

2. Add ads from any network

Adsterra, Google AdSense, PropellerAds, Monetag or any other network — paste each code into its own slot: popunder, top banner, in-content, native, social bar and sticky footer.

🚀

3. Publish & host here

One click in the Publish tab puts your page live on this PageCraft domain at your own page address. Templates stay on PageCraft — they are hosted, never downloaded.

Free & Pro: Templates marked Free are fully usable. Templates marked Pro open in the builder so you can design with them; hosted Pro pages keep a small “Made with PageCraft” line in this free version. Templates cannot be downloaded — every page is hosted on this domain instead.

Host it yourself — GitHub + Vercel setup

This site is a single static index.html — no build step, no server. That makes it ready for GitHub + Vercel: push the file to a repo, import the repo in Vercel, and you are live. Use the same setup for any PageCraft project you maintain in code.

① Push to GitHub

  1. Create a new repository on GitHub — e.g. pagecraft (Public, no template).
  2. Add index.html at the repo root — this file. Keep assets, if any, in an assets/ folder at the root.
  3. Add the vercel.json on the right at the root, next to index.html.
  4. Commit & push — every later push will auto-redeploy.
git init git add index.html vercel.json git commit -m "PageCraft — first deploy" git branch -M main git remote add origin https://github.com/YOUR-USERNAME/pagecraft.git git push -u origin main
git init git add index.html vercel.json git commit -m "PageCraft — first deploy" git branch -M main git remote add origin https://github.com/YOUR-USERNAME/pagecraft.git git push -u origin main

② Deploy on Vercel

  1. Vercel → Add New → Project → Import your GitHub repo.
  2. Framework Preset: Other • Build Command: leave empty • Output Directory: leave empty (root).
  3. Click Deploy — live in under a minute at your-project.vercel.app.
  4. Optional: Settings → Domains → add your custom domain.
