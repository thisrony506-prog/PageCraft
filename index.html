Admin

AI setup — admin only

PageCraft's AI runs on the site admin's Gemini API key. Regular visitors use AI without ever seeing a key: their browser only talks to this site's own /api/gemini proxy, and the key itself lives only in the server's environment variables — never in this page's code and never in any visitor's browser.

Step 1 — Get the admin Gemini API key

  1. Open Google AI Studio with the admin's Google account.
  2. Go to API Keys and create a key for the Gemini API. Keep it private — anyone with this key can spend the admin's quota.

The key is not pasted into PageCraft's code. It is only copied into the hosting server in Step 3.

Step 2 — Copy the key for the server

Paste the admin key here only to copy it in the exact format Vercel needs. This field is never saved, never stored and never sent anywhere — it stays in this tab until you clear it.

Step 3 — Add the key on Vercel (server side)

  1. Vercel dashboard → your PageCraft project → Settings → Environment Variables.
  2. Name: GEMINI_API_KEY — Value: paste the key from Step 2. Apply to Production (and Preview if you want AI there too).
  3. Redeploy the project so the new variable takes effect.

Environment variables exist only on the server. The deployed page code never contains the key.

Step 4 — Add the /api/gemini proxy function

Create a file named api/gemini.js in the project root (next to index.html) with this code, commit it to GitHub, and Vercel will deploy it as a serverless function. It reads the key from the environment and calls Gemini — browsers only ever see this endpoint.

// api/gemini.js — Vercel serverless proxy for PageCraft AI export default async function handler(req, res) { if (req.method !== "POST") return res.status(405).json({ error: "Method not allowed" }); const key = process.env.GEMINI_API_KEY; if (!key) return res.status(503).json({ error: "Admin key not configured" }); const prompt = (req.body && req.body.prompt) || ""; if (!prompt) return res.status(400).json({ error: "Missing prompt" }); const r = await fetch("https://generativelanguage.googleapis.com/v1beta/models/gemini-2.0-flash:generateContent?key=" + key, { method: "POST", headers: { "Content-Type": "application/json" }, body: JSON.stringify({ contents: [{ parts: [{ text: prompt }] }] }) }); const data = await r.json(); const text = (data.candidates && data.candidates[0] && data.candidates[0].content.parts[0].text) || ""; return res.status(200).json({ text: text }); }

After deploying, press Check AI Status above. Until the proxy and key exist, every AI button in PageCraft shows the setup guidance instead of asking anyone for a key.

Add PageCraft to your Home Screen

PageCraft works like an app once it is on your home screen — it opens full-screen with its own PC icon, no browser bar. Follow the steps for your device:

Android — Chrome
  1. Tap the three-dot menu at the top-right of Chrome.
  2. Tap "Add to Home screen" (or "Install app").
  3. Confirm with Add — the PageCraft icon appears on your home screen.
iPhone / iPad — Safari
  1. Tap the Share button in Safari's toolbar.
  2. Scroll down and tap "Add to Home Screen".
  3. Tap Add — PageCraft is now on your home screen.
Desktop — Chrome / Edge
  1. Click the install icon at the right end of the address bar.
  2. Or open the browser menu and choose "Install PageCraft".
