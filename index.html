Not just Adsterra — paste ad codes from any network: Adsterra, Google AdSense, PropellerAds, Monetag or any other. Pick the network for each slot, paste its code exactly as the network gives it, and it runs in that slot on your live page.

How to set up ads correctly — 4 steps

  1. Create the ad unit in your network dashboard first (Adsterra: Websites → your site → Add Ad Unit. AdSense: Ads → By ad unit. PropellerAds / Monetag: Sites → Zones).
  2. Match the format to the right slot below — use the slot map. A code in the wrong slot will not show properly.
  3. Copy the FULL code — every <script> tag, exactly as given. Do not shorten it, do not paste only a link.
  4. Publish, then open the live page to test. Real ads never load inside the builder preview — that protects your account from invalid self-impressions. They load on the published live page.
